📋 Component Legend

Event Sources (Purple) External systems that trigger events: GitHub, Slack, Cron, Custom webhooks
Ingestion Layer (Pink) HTTP server, authentication, and payload validation for incoming events
Processing Pipeline (Blue) Event routing, filtering, transformation, and queueing for async processing
CUGA Core (Green) LangGraph agent, policy system, tool registry, and session management
Event Handlers (Pink-Yellow) Main session, isolated session, and batch handlers for different execution modes
Delivery Layer (Orange) Output channels: Slack, GitHub, webhooks, and persistent event storage

🎯 Key Event Flows

  • GitHub PR Flow: GitHub → HTTP Server → Auth → Router → Queue → Isolated Handler → Agent → GitHub Comment
  • Slack Mention Flow: Slack → HTTP Server → Auth → Router → Queue → Isolated Handler → Agent → Slack Reply
  • Cron Job Flow: Cron Scheduler → Queue → Main/Isolated Handler → Agent → Delivery Channel
  • Custom Webhook Flow: Custom System → HTTP Server → Auth → Router → Queue → Handler → Agent → Response

⚡ Performance Characteristics

  • Throughput: 100+ events per second
  • Latency: <2 seconds average processing time
  • Reliability: 99%+ success rate with automatic retries
  • Scalability: Redis-backed queue for horizontal scaling
